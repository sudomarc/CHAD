CHAD

Local-first general-purpose coding agent

v0.1.1
Présentation

CHAD est un agent de codage local-first conçu pour travailler dans n'importe quel dépôt local. Il combine une interface terminal UI (TUI), un runtime agent borné, une passerelle de modèle multi-provider, des outils aware du dépôt et des contrôles de sécurité explicites.

Langage principal : Python pour lorchestration et la logique produit ; Rust pour les composants natifs justifiés.

Modèle d'implantation : local-first ; pas de service CHAD hébergé obligatoire.

Objectif et fonctionnalités
  • Orchestration Python-first : tout le comportement, les providers et le TUI sont en Python.
  • Passerelle de modèle multi-provider : providers interchangeables (Anthropic, OpenAI, Google, LapisLLM).
  • Interface terminal (TUI) : interface Textual pour une expérience CLI riche.
  • Runtime borné : boucle observe/décider/act bornée avec contrôle des permissions.
  • Conscience du dépôt : outils filesystem, git, shell conscients du dépôt.
  • Sécurité explicite : politique ReadOnly par défaut, pas de copie silencieuse d'exceptions.
Plateformes et environnements compatibles
  • Debian/Ubuntu (via dépôt APT)
  • Distribution Linux générique (installation manuelle possible)
  • Environnement Python 3.11+
  • Interface terminal (TUI) nécessitant Textual
Prérequis
  • Système d'exploitation : Debian 12+, Ubuntu 22.04+, ou distribution Linux compatible
  • Python 3.11 ou version supérieure
  • Accès en ligne de commande (terminal)
  • Connexion internet (pour l'installation initiale depuis le dépôt)
Installation

Choisissez la méthode qui vous convient :

Installation via APT (recommandé)

Ces commandes sont copiables individuellement :

Configuration du dépôt curl -fsSL https://sudomarc.github.io/CHAD/apt/KEY.gpg | sudo gpg --dearmor -o /usr/share/keyrings/chad-archive-keyring.gpg
Ajouter la source APT echo "deb [arch=amd64 signed-by=/usr/share/keyrings/chad-archive-keyring.gpg] https://sudomarc.github.io/CHAD/apt stable main" | sudo tee /etc/apt/sources.list.d/chad.list
Mise à jour et installation sudo apt update && sudo apt install chad
Vérification de l'installation chad --version
Première utilisation chad run "ta tâche d'inspection ou de modification"
Installation manuelle

Si l'installation APT n'est pas disponible ou adaptée :

Via pip pip install git+https://github.com/sudomarc/CHAD.git
Depuis les sources git clone https://github.com/sudomarc/CHAD.git && cd CHAD && pip install -e .
Commandes de mise à jour
sudo apt update && sudo apt upgrade chad
Pour mettre à jour vers une version spécifique : sudo apt install chad=0.1.1
Commandes de désinstallation
sudo apt remove chad
Suppression complète incluant les dépendances non utilisées : sudo apt autoremove chad
Dépannage
  • Commande introuvable : Vérifiez que `/usr/share/keyrings/chad-archive-keyring.gpg` existe et que la source APT est correcte.
  • Erreur de signature : Réimportez la clé GPG : curl -fsSL https://sudomarc.github.io/CHAD/apt/KEY.gpg | sudo gpg --dearmor -o /usr/share/keyrings/chad-archive-keyring.gpg
  • Package non trouvé : Exécutez sudo apt update puis vérifiez que la source APT est correctement ajoutée.
  • chad --version ne répond pas : Vérifiez que le wrapper chad est bien dans /usr/bin.
Exemples d'utilisation
  • chad run "inspecter ce dépôt" — Exécute une tâche d'inspection.
  • chad tui — Lance l'interface terminal interactives.
  • chad --helpAffiche l'aide en ligne de commande.
