# Architecture Decision Records

Store durable architecture decisions in this directory.

## Naming

Use:

`NNNN-short-kebab-case.md`

Example:

`0001-model-gateway-boundary.md`

## Required sections

- Context
- Decision
- Alternatives considered
- Consequences
- Verification / follow-up

## Rules

Create or update an ADR when a decision changes a stable architectural boundary, persistence contract, provider contract, security boundary, or deployment topology.

ADRs record decisions. They do not replace implementation documentation or tests.
