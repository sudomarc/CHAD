CHAD is the agent runtime and user-facing product in the three-repository AI ecosystem.

Vibe Coding Instructions owns portable agent governance, skills, evidence rules, token economics, and role contracts.

CHAD owns the product, agent orchestration, tools, permissions, memory, files, UX, and model gateway.

LapisLLM owns model architecture, tokenization, training, checkpoints, inference, generation, and model runtime metadata.

Dependency direction: CHAD -> LapisLLM. CHAD may consume selected Vibe Coding Instructions policies, but Vibe is not a second runtime.

Material cross-repository contract changes require synchronized documentation and compatibility verification.

- https://github.com/sudomarc/CHAD
