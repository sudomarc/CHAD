Installer CHAD

Sur amd64, utilise le dépôt APT signé pour installer CHAD et recevoir ses mises à jour. Le paquet Debian direct sert de solution de secours ou d'alternative pour les autres architectures compatibles.

Dépôt signé disponible

Debian / Ubuntu — APT

Dépôt signé recommandé sur les systèmes amd64. Les index de paquets sont générés et publiés avec la signature CHAD.

1. Vérifier l'architecture (doit afficher amd64)
dpkg --print-architecture
2. Importer la clé publique
sudo install -d -m 0755 /usr/share/keyrings && curl -fsSL https://sudomarc.github.io/CHAD/apt/KEY.asc | sudo gpg --dearmor --yes -o /usr/share/keyrings/chad-archive-keyring.gpg
3. Ajouter la source APT
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/chad-archive-keyring.gpg] https://sudomarc.github.io/CHAD/apt stable main" | sudo tee /etc/apt/sources.list.d/chad.list
4. Actualiser et vérifier la présence du paquet
sudo apt update && apt-cache policy chad

Vérifie que Candidate affiche une version de CHAD avant l'installation.

5. Installer CHAD
sudo apt install chad
6. Mettre à jour CHAD
sudo apt update && sudo apt upgrade chad
Configuration du dépôt en attente

Dépôt APT signé

Le dépôt APT signé n'est pas activé pour cette publication. Utilise le paquet Debian direct lorsqu'il est affiché, ou pipx depuis Git.

La vérification cryptographique APT n'est jamais désactivée. N'ajoute pas de source non signée ou marquée trusted=yes.
Solution de secours

Paquet Debian direct

Installe directement le paquet de cette version. Cette méthode évite les problèmes de synchronisation de l'index APT CHAD et fonctionne sur les architectures compatibles avec Python 3.11+.

1. Télécharger le paquet
curl -fLO https://sudomarc.github.io/CHAD/downloads/chad_0.1.0_all.deb
2. Installer le paquet local
sudo apt install ./chad_0.1.0_all.deb
3. Vérifier
chad --version
Cette installation ne configure pas le dépôt APT CHAD. Pour mettre à jour, télécharge et installe le nouveau fichier .deb depuis ce site.
Depuis Git

Installation Python avec pipx

Installe la version source dans un environnement Python isolé. Pour installer CHAD depuis Git et ajouter la dépendance de son interface TUI.

1. Installer pipx
sudo apt update && sudo apt install pipx python3-venv git
2. Installer CHAD
pipx install git+https://github.com/sudomarc/CHAD.git
3. Installer la dépendance de l'interface TUI
pipx inject chad "textual>=8.0"

Un problème avec APT ?

Un dépôt peut répondre avec ses métadonnées signées sans que le paquet soit disponible dans l'index local.

Erreur « Unable to locate package chad »

Vérifie l'architecture et la version candidate avant de relancer l'installation.

1. Architecture native (le dépôt APT CHAD prend actuellement en charge amd64)
dpkg --print-architecture
2. Vérifier si APT connaît le paquet
apt-cache policy chad

Si Candidate: (none) apparaît, même après sudo apt update, ne désactive pas la vérification des signatures. Sur amd64, renouvelle les index CHAD :

sudo rm -f /var/lib/apt/lists/*sudomarc.github.io*CHAD* && sudo apt update

Vérifie ensuite apt-cache policy chad. Si aucune version candidate n'apparaît, utilise le paquet Debian direct ci-dessus. Si l'architecture n'est pas amd64, utilise également le paquet direct, compatible grâce à Architecture: all, sous réserve de Python 3.11+.

Le message Hit: ... CHAD ... InRelease ne suffit pas à confirmer que le paquet est installable. Ne configure jamais trusted=yes et ne désactive jamais apt-secure.

Prérequis

Le paquet Debian ne contient pas d'environnement virtuel propre à une machine et n'exécute pas pip avec les privilèges système.

Python 3.11+Fourni par le système ou installé séparément.
Debian / UbuntuAPT CHAD : amd64 uniquement. Le paquet direct est Architecture: all.
Fournisseur de modèleUne clé API est nécessaire pour appeler un vrai modèle distant.

Conçu pour les dépôts réels

L'architecture vise à garder l'interface, le runtime, les fournisseurs et les outils clairement séparés.

Runtime borné

Budgets, limites d'exécution et résultats structurés pour éviter les boucles sans fin.

Passerelle multi-modèles

Contrat commun pour intégrer plusieurs fournisseurs sans lier le runtime à un seul service.

Contrôles explicites

Outils et permissions séparés, avec une attention particulière aux frontières du workspace.
